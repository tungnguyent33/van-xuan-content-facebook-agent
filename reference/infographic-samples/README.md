# Ảnh mẫu infographic

Bỏ vào đây 2-3 ảnh infographic đẹp nhất, đúng màu/logo/phông chữ Vạn Xuân đang dùng (nếu chưa có, lấy ảnh bài đăng đẹp nhất từng đăng làm mẫu). Claude sẽ dùng các ảnh này làm "reference image" khi tạo infographic mới, để giữ đúng style thương hiệu thay vì bịa ra màu sắc ngẫu nhiên.
